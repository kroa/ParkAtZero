# TASK-003: 272개 정적 페이지 및 홈 상호 링크 크롤 배관(Crawl Graph) 전수 점검 명세서

- **과제 ID**: TASK-003

- **우선순위**: P1
- **담당**: 기획(서하은), 아키텍트(도경민), 개발(오준호), QA(차은결)

- **상태**: 진행 중 (In Progress)

## 2. 배경 및 목적

### 2.1 배경 및 히스토리
- **홈 렌더링 후 링크 소실 (해결됨)**: 이전에는 React SPA 마운트 시 정적 소개문이 지워져 크롤러 기준 내부 링크가 0개가 되는 막다른 골목(Dead-end) 현상이 있었습니다. 이는 `FooterLinks.tsx`를 통해 홈 하단에 6개 내부 링크(`/지역/`, 상황 5개)를 배치하여 1차 해결되었습니다.
- **교차 30쪽 고아 페이지 이력**: 과거 빌드 스크립트 실행 순서 문제로 인해, 시·도 페이지가 먼저 생성되고 교차 페이지가 나중에 결정되어 시·도 페이지에서 교차 페이지로 가는 링크가 누락된 적이 있습니다. 그 결과 교차 30쪽이 `sitemap.xml`에는 존재하지만 내부 링크로는 닿지 않는 완전한 **고아 페이지(Orphan Page)**가 되었습니다.

### 2.2 목적
- 검색엔진 크롤러(Googlebot, Naver Yeti, Bingbot 등)는 사이트맵뿐만 아니라 HTML 내 `<a>` 링크를 따라가며 문서를 발견하고 사이트 내 신뢰도 및 가중치(PageRank)를 분배합니다.
- 홈(`/`)에서 시작하여 오직 내부 `<a>` 링크만을 재귀 탐색(BFS/DFS)했을 때, **전체 273개 URL(홈 1 + 지역 242 + 상황 5 + 교차 30) 모두에 고아 페이지(0건) 없이 100% 도달**할 수 있는지 전수 검증하고 영구적인 배관 무결성을 확보합니다.

## 3. 대상 페이지군 및 크롤 토폴로지 (Crawl Graph Topology)

### 3.1 대상 페이지 구성 (총 273쪽)
1. **홈 (1쪽)**: `/` (SPA 렌더링 후 FooterLinks 6개 링크 유지)
2. **지역 페이지군 (242쪽)**:
   - 지역 인덱스 (1쪽): `/지역/`
   - 시·도 허브 페이지 (16쪽): `/지역/{시도}/` (세종은 시군구가 없어 단독 목록 페이지로 대체)
   - 시·군·구 세부 페이지 (225쪽): `/지역/{시도}/{시군구}/`
3. **상황 페이지군 (5쪽)**:
   - 전국 상황별 페이지: `/공휴일-무료주차장/`, `/야간-무료주차장/`, `/일요일-무료주차장/`, `/토요일-무료주차장/`, `/24시간-무료주차장/`
4. **지역 × 상황 교차 페이지군 (30쪽)**:
   - 시·도별 상황 페이지: `/지역/{시도}/{상황-slug}/`

### 3.2 링크 배관 연결 계층 및 규칙
- **Level 0 (진입점)**: 홈 (`/`)
  - Outbound: `/지역/`, 상황별 5개 페이지 (`/{상황}/`)
- **Level 1 (대분류 허브)**:
  - `/지역/`: 17개 시·도 링크 목록 제공
  - `/{상황}/` (5개): 시·도별 목록 표에서 교차 페이지가 존재하는 시도는 해당 교차 페이지(`/지역/{시도}/{상황}/`)로, 없는 시도는 시도 허브(`/지역/{시도}/`)로 연결
- **Level 2 (시·도 및 상황 세부)**:
  - `/지역/{시도}/` (16개):
    - 해당 시도의 시·군·구 페이지 목록 (`/지역/{시도}/{시군구}/`)
    - 해당 시도의 교차 페이지 목록 (`/지역/{시도}/{상황}/`)
    - 상단 브레드크럼 (`/`, `/지역/`)
  - `/지역/{시도}/{상황}/` (30개 교차 페이지):
    - 해당 시도 내 시군구 페이지 링크
    - 해당 시도의 다른 상황 교차 링크
    - 전국 상황 페이지 (`/{상황}/`), 시도 전체 무료 페이지 (`/지역/{시도}/`), `/지역/` 링크
    - 상단 브레드크럼 (`/`, `/지역/`, `/지역/{시도}/`)
- **Level 3 (시·군·구 리프 페이지)**:
  - `/지역/{시도}/{시군구}/` (225개):
    - 동일 시도 내 다른 시군구(형제자매) 링크
    - 지도 딥링크 (`/?lat=...&lng=...`)
    - 상단 브레드크럼 (`/`, `/지역/`, `/지역/{시도}/`)

## 4. 수용 기준 (Acceptance Criteria, AC)

팀원 간 정렬 및 검증 합격을 위해 아래 5가지 기준을 모두 만족해야 합니다.

### [AC-1] 크롤 도달성 100% (Crawl Reachability)
- 홈(`/`)을 루트 노드로 하여 페이지 내 실제 `<a>` 태그의 `href`만을 재귀 탐색(BFS)했을 때, `sitemap.xml` 및 `dist/region-pages.json`에 정의된 **전체 273개 URL에 모두 도달(Reachability 100%)**해야 한다.
- 도달하지 못하는 미도달 페이지 수는 **0건**이어야 한다.

### [AC-2] 고아 페이지(Orphan Page) 제로
- 273개 모든 페이지는 최소 1개 이상의 외부 인바운드 내부 링크(Inbound Internal Link)를 보유해야 한다 (홈 제외).
- 특히 과거 누락 이력이 있었던 **교차 30쪽 전수**에 대해 `/지역/{시도}/` 및 `/{상황}/`으로부터의 정상 인바운드 링크가 존재하는지 확인되어야 한다.

### [AC-3] 깨진 내부 링크(Broken Internal Link) 제로
- 273개 페이지 내에 존재하는 모든 내부 링크 대상 URL은 실제 정적 파일(200 OK)로 존재해야 한다.
- 내부 링크 중 `404 Not Found`, 리다이렉트 루프, SPA 에러 폴백(`/JavaScript 가 필요합니다/`)으로 연결되는 링크가 **0건**이어야 한다.

### [AC-4] 크롤 깊이(Click Depth) 상한 보장
- 홈(`/`)에서 임의의 모든 정적 페이지(시군구 및 교차 페이지 포함)까지의 최단 도달 거리(Shortest Click Path)는 **최대 3클릭(홉) 이하**여야 한다. (구글봇의 탐색 비용 최소화)
  - 예: 홈(0) ➔ `/지역/`(1) ➔ 서울(2) ➔ 종로구(3)
  - 예: 홈(0) ➔ 야간 무료(1) ➔ 서울 야간(2) ➔ 종로구(3)

### [AC-5] 자동화 배관 점검 스크립트/테스트 구축
- 빌드 산출물(`dist/`)을 정적으로 순회하여 상기 AC-1 ~ AC-4를 전수 검증하는 고속 스크립트(또는 테스트)가 마련되어야 한다.
- `npm run seo:check` 또는 전용 스크립트(`npm run seo:crawl` 등)로 3초 이내에 자동 검증이 완료되고 배포 파이프라인(CI)에서 게이트 역할을 수행할 수 있어야 한다.
