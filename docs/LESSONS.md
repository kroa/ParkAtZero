## 기록 목록

### 1. PowerShell 한 줄 명령어 실행 오류 (2026-09-27)
- **상황**: PowerShell 터미널에서 여러 명령어를 세미콜론이나 파이프로 연결하여 실행하려다 문법 오류 및 인코딩 깨짐 발생.
- **원인**: Windows PowerShell 환경의 실행 정책 및 한 줄 복합 명령어 처리 차이.
- **조치**: 복합 작업은 반드시 실행용 스크립트 파일(`.bat`)을 생성하여 단독 실행하도록 원칙 수립 후 `AGENTS.md`에 반영.

### 2. 홈 렌더링 후 내부 링크 0개 소실 (함정 11) (2026-10-05)
- **상황**: 원본 HTML에는 23개 내부 링크가 정적으로 주입되었으나 React 마운트 후 DOM에서 사라져 크롤이 중단됨.
- **원인**: React가 `#root` 내부를 덮어쓰면서 기존 정적 HTML 태그를 모두 초기화함.
- **조치**: React 앱 내부 컴포넌트(`FooterLinks`)로 실제 `<a>` 태그를 직접 렌더링하도록 수정하고 E2E 테스트로 검증.
