# ADR-004: 3단계 반응형 뷰포트 계층 및 태블릿 지도 시야 보장 아키텍처

## 상태
승인됨 (Approved) - 2026-11-23

## 맥락
- 기존 2단계 뷰포트(isDesktop: >= 768px) 체계로 인해, 폭 768px~1023px 구간의 태블릿 환경에서 사이드바(404px)와 상세 패널(380px)의 합(784px)이 화면 너비를 초과하여 지도를 100% 가려버리는 치명적인 레이아웃 결함이 존재했음.
- 운전자의 75% 이상이 모바일/태블릿으로 접속하므로, 한 손 조작성(터치 타깃 44×44px, Safe Area)과 지도 가시성 확보가 필수적임.
- "AI 티 방지" 원칙에 따라 과도한 글래스모피즘(블러 32px)과 보라-파랑 그라데이션을 배제하고 실용적 매트 UI로 정제해야 함.

## 결정
1. **3단계 뷰포트 티어 확립**:
   - Compact (< 768px): 모바일 상단 플로팅 + 바텀시트 Peek(152px)
   - Medium (768px ~ 1023px): 태블릿 슬림 사이드바(360px) + 사이드바 영역 내 Slide-over 상세 패널 (우측 지도 53% 이상 가시성 고정 보장)
   - Expanded (>= 1024px): 데스크톱 사이드바(404px) + 우측 독립 상세 패널(380px) 병렬 2열
2. **`useMediaQuery.ts` 확장**:
   - `useViewportTier()`를 단일 진실 공급원(SSOT)으로 도입하고 하위 호환성 제공.
3. **`mapPadding` 계산 최적화**:
   - 태블릿에서는 상세 패널이 열려도 `mapPadding.left`를 360px로 고정하여 지도 가시 영역 중앙에 정확히 마커를 배치.
4. **터치 타깃 44×44px 및 매트 배경(불투명도 95%) 적용**:
   - 모든 닫기/필터/시간 버튼의 최소 터치 영역을 44px로 확장하고 가독성을 확보.

## 결과 및 장점
- 태블릿 뷰포트에서 지도가 가려지는 버그 원천 해결 및 53% 이상 가시 영역 영구 확보.
- 모바일 바텀시트 Peek 높이 최적화(152px)로 진입 즉시 75% 이상의 지도 공간 확보.
- 운전자 주행 전/정차 중 한 손 엄지 조작 오류 대폭 감소.
