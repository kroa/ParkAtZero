# ADR-003: 로컬 인메모리 BFS 기반 정적 크롤 그래프 검증 시스템 도입

## 상태
승인됨 (Approved) - 2026-11-23

## 맥락
- 정적 사이트(273쪽)는 검색엔진이 내부 링크를 통해 모든 페이지를 크롤링해야 함.
- 과거 빌드 순서 결함으로 교차 페이지 30쪽이 sitemap.xml에만 존재하고 실제 링크로는 도달할 수 없는 고아 페이지가 되는 문제가 발생했음.
- 원격 HTTP 요청 기반의 check-seo.mjs는 네트워크 부하와 시간 지연으로 인해 빌드 루프 내에서 고아 페이지 및 최단 홉 수(BFS)를 전수 계산하기에 부적합함.

## 결정
1. 빌드 직후 산출물(dist/)을 직접 읽어 메모리 상에서 BFS를 수행하는 scripts/check-crawl-graph.mjs를 구축한다.
2. 외부 의존성 없이 순수 Node.js 내장 모듈로 1초 이내에 273개 전 페이지의 5대 수용 기준(도달률 100%, 고아 0건, 깨진 링크 0건, 클릭 깊이 <= 3홉, 자동화 게이트)을 판정한다.
3. build:only 파이프라인의 최종 관문으로 배치하여 배관 결함 시 배포를 즉시 차단(Fail-Fast)한다.

## 결과 및 장점
- 고아 페이지 및 깨진 링크의 프로덕션 배포 원천 차단.
- CI 실행 시간 증가 없이(1초 미만) 크롤 토폴로지 영구 무결성 보장.
