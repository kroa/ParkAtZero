# ParkAtZero 작업 백로그 (BACKLOG.md)

이 문서는 ParkAtZero의 우선순위 과제 목록을 관리합니다. 기획자 서하은이 관리하며, 팀장 윤도한이 다음 작업을 선정합니다.

## 우선순위 규칙
- P0: 서비스 핵심 가치("0원 주차 여부") 오류, 데이터 부정확성, 검색 크롤 차단
- P1: 검색엔진 유입 개선, 사용자 편의 핵심 기능, 성능 최적화
- P2: UI/UX 고도화, 추가 편의 기능, 신규 데이터 소스 발굴
