# ParkAtZero · 0원 주차

> 방문할 **날짜·시각·주차 시간**을 고르면, 그 순간 **0원으로 댈 수 있는 주차장만** 초록으로 골라 보여주는 Local-First 웹앱.
> 회원가입도, 설치도 없습니다.

**배포:** https://parkatzero.pages.dev

---

## 왜 만들었나

공공데이터포털의 「전국주차장정보표준데이터」에는 요금·운영시간·특기사항이 모두 들어 있습니다.
그런데 대부분의 서비스는 "유료 / 무료" 두 글자만 보여줍니다.

실제로 운전자가 알고 싶은 건 이겁니다.

> **"내가 목요일 저녁 7시에 두 시간 대면, 얼마 나와?"**

ParkAtZero 는 그 질문 하나에 답하도록 만들었습니다.
요금표·운영시간·특기사항을 시간축 위에 펼쳐 놓고 선택한 방문 구간과 겹쳐 계산합니다.

## 상태 컬러 시스템

| 색 | 상태 | 의미 |
|---|---|---|
| 🟢 **초록** | `free` | 선택한 방문 구간 **전체가 조건 없이 0원** (무료 주차장 / 그 시간대 전면 무료) |
| 🟠 **주황** | `conditional` | 0원이지만 **조건이 붙음** — 최초 N분 무료로 0원이 되었거나, 구간 일부만 무료 |
| ⚪ **회색** | `paid` | 그 시간대는 **요금 발생** |
| ⚫ **짙은 회색** | `closed` | **운영시간 밖** |

색은 `src/lib/statusStyle.ts` 한 곳에서만 정의됩니다. 뱃지·지도 마커·카드 강조선·필터칩이 모두 이 파일을 참조하므로, 팔레트를 바꾸려면 이 파일만 고치면 됩니다.

> **왜 "19시 이후 무료"가 초록인가?**
> 뱃지는 *주차장의 일반적 성격*이 아니라 *당신이 고른 그 시간*을 말합니다.
> 20시에 2시간 대는 사람에게 그곳은 조건부가 아니라 그냥 0원입니다.
> 반대로 "최초 1시간 무료"는 더 오래 대면 요금이 붙으므로 0원이어도 주황을 유지합니다.

## 시간 판별 로직

핵심은 세 파일입니다.

```
src/lib/timeRules.ts   운영시간 파싱 · 특기사항에서 '무료 규칙' 추출
src/lib/freeCalc.ts    방문 구간과 규칙을 겹쳐 상태·예상요금 산출
src/lib/interval.ts    구간 교집합/합집합 산술
```

### 1) 무료 규칙 추출 (`extractFreeRules`)

특기사항(`spcmnt`)은 자유 서술이라 정형화가 불가능합니다.
그래서 **좁은 표현부터 먹어 치우고 마스킹하는** 순서를 씁니다.

```
1. 시간대 구간   "20시~08시 무료"      → window(1200 → 480, 자정 넘김)
2. 이후/부터     "19시 이후 무료"       → window(1140 → 1440)
3. 이전/까지     "08시 이전 무료"       → window(0 → 480)
4. 야간/심야     "야간 무료"            → window(1200 → 480) + inferred 플래그
5. 최초 N분      "최초 30분 무료"       → grace(30)
6~7. 남은 절     "토요일 및 공휴일 무료" → dayType([saturday, holiday])
```

해석이 끝난 구간은 **제어문자(U+0001)로 덮습니다.** 공백으로 덮으면 뒤따르는 정규식의 `\s*`가
마스킹 구간을 가로질러 `"평일 19시 이후 무료 개방"`을 `"평일 전일 무료"`로 잘못 확장합니다.

대상 한정 문구(`경차 무료`, `장애인 면제`)는 **모두에게 적용되지 않으므로** 별도 분류(`targeted`)해
요금 계산에서 제외하고 안내 문구로만 노출합니다.

### 2) 요금 계산 (`evaluate`)

```
운영구간 = 요일별 운영시간을 방문 당일 자정 기준 절대 분으로 펼침 (전후 며칠까지)
무료구간 = 규칙 구간 ∩ 방문구간
과금시간 = |운영구간 ∩ 방문구간| − |무료구간 ∩ 운영구간|
예상요금 = 기본요금 + ceil((과금시간 − 기본시간) / 추가단위시간) × 추가단위요금
           ↳ 1일 주차권 요금이 있으면 상한(cap) 적용
```

**이중 차감 주의점 —** 요금표가 이미 `기본요금 0원 + 기본시간 30분` 구조라면
`computeCost`가 그 30분을 빼 줍니다. 여기에 `grace(30)`을 또 빼면 요금이 절반으로 줄어듭니다.
그래서 `graceInFee` 판정으로 **요금 계산용 grace**와 **표시용 grace**를 분리합니다.

### 3) 운영시간이 비어 있을 때

표준데이터에는 운영시간 컬럼이 빈 레코드가 많습니다. 이때 `operDay`(운영요일)로 갈라집니다.

- 운영요일에 **포함된** 날 → 24시간 개방으로 가정하고 카드에 `추정` 뱃지
- 운영요일에서 **빠진** 날 → 그날은 미운영 (`closed`)

`operatesOn()`이 한 글자 패턴(`일`, `토`)을 쓰지 않는 이유도 여기 있습니다.
한국어에는 단어 경계가 없어 `/일/`은 **"평일"**에도 걸리고, 그러면 `"평일+토요일"` 주차장이
공휴일에도 운영하는 것으로 잘못 읽힙니다.

### 4) 공휴일

음력 기준 명절은 계산식으로 뽑을 수 없어 `src/lib/holidays.ts`에 **2025–2027 정적 테이블**을 둡니다.
매년 관보 확정 후 갱신이 필요하며, 공공데이터포털 「특일 정보」 API 로 바꾸려면
`setHolidaySource(dates)` 하나만 호출하면 됩니다.

## Local-First 로딩

```
1. localStorage 캐시  →  있으면 즉시 방출 (네트워크 대기 0ms)
2. 번들 동봉 시드 JSON →  캐시가 없을 때. 오프라인에서도 동작
3. 원격 API           →  백그라운드 갱신. 실패해도 화면은 이미 살아 있음
```

`src/lib/dataSource.ts`가 단계마다 콜백을 쏘므로 UI 는 점진적으로 갱신됩니다.
E2E 테스트에서 **외부 네트워크를 전부 차단해도** 목록과 지도가 뜨는 이유입니다.

---

## 지도

기본은 **MapLibre GL + CARTO 베이스맵**(API 키 불필요, 라이트/다크 타일 분리)입니다.
스타일을 원격 `style.json` 대신 **인라인 객체**로 넘겨 초기 로딩 요청을 하나 줄였습니다.

WebGL 을 못 쓰거나 지도가 6초 안에 뜨지 않으면 **간이 지도(`MapFallback`)** 로 자동 전환합니다.
배경 타일은 없지만 Web Mercator 투영으로 마커 위치를 정확히 그리고,
**마커 마크업과 테스트 셀렉터가 실제 지도와 100% 동일**하므로 기능도 테스트도 그대로 동작합니다.

```bash
npm install
cp .env.example .env.local     # 필요한 값만 채우면 됩니다 (전부 비워도 동작)
```

## 테스트

`tests/parking.spec.ts` — 데스크톱/모바일 두 프로젝트로 **65개** 케이스가 돕니다.

- **초기 로딩** 외부 네트워크 전면 차단 상태에서의 렌더, 캐시 복원
- **시간 판별** 평일/토요일/공휴일 × 낮/저녁/심야 × 주차 시간별 상태 전환
- **검색** 자동완성, 이름 필터, 빈 상태
- **필터** 0원만 / 조건부 포함 / 반경 / 정렬
- **상세·길안내** 4개 앱 딥링크의 좌표·파라미터 검증
- **지도** 마커 개수·색상·클릭, 내 위치
- **광고** 슬롯 자리 예약과 레이아웃 시프트(CLS) 없음
- **바텀 시트** 탭 토글, 스와이프 스냅
- **판정 로직** `window.__parkatzero` 브리지로 순수 함수를 직접 호출

마지막 항목이 핵심입니다. UI 만으로는 "공휴일 미운영", "자정을 넘기는 야간 무료" 같은
경계 조건을 다 훑기 어렵습니다. `src/lib/testBridge.ts` 가 **실제 배포되는 번들의 순수 함수**를
`window` 에 노출하므로, 별도 유닛 테스트 러너 없이 같은 코드로 단위 수준 검증까지 합니다.
브리지는 별도 청크(~0.7 kB)로 분리되어 있고 `import.meta.env.DEV || VITE_E2E` 일 때만 동적 import 되므로,
프로덕션에서는 **한 번도 내려받지 않습니다.**

외부 의존은 `tests/helpers.ts`의 `blockExternal()`이 전부 차단합니다 —
지도 타일, 광고 스크립트, 웹폰트 CDN. 테스트는 완전히 오프라인에서 재현됩니다.

### 개발 서버 스모크 (`tests/dev-smoke.spec.ts`)

기본 E2E 는 **프로덕션 빌드**를 검증합니다. 그런데 React StrictMode 의 이펙트 이중 실행
(마운트 → 정리 → 재마운트)은 **개발 모드에서만** 일어납니다. 그래서
"정리 단계에서 취소된 요청이 재시도되지 않아 목록이 영영 비는" 부류의 결함은
프로덕션 테스트로는 원리상 잡을 수 없습니다 — 실제로 한 번 그렇게 새어 나갔습니다.

```bash
터미널 1:  npm run dev
터미널 2:  npm run test:dev
```

dev 서버가 꺼져 있으면 실패가 아니라 자동으로 건너뜁니다. CI 에서는 돌지 않습니다.

## 보안

- 브라우저에 노출되는 값은 **`VITE_` 접두사가 붙은 것뿐**이며, 이 값들은 번들에 그대로 박힙니다.
  공공데이터포털 인증키처럼 비공개여야 하는 값은 **절대** `VITE_` 를 붙이지 마세요.
- 비공개 키는 `functions/api/parkings.ts` 프록시가 서버(엣지)에서만 사용합니다.
  프록시는 엣지 캐시로 원본 API 호출량도 함께 줄입니다.
- `.env.local`, `.dev.vars` 는 `.gitignore` 에 등록되어 있습니다. `.env.example` 만 커밋됩니다.
- 보안 헤더는 `public/_headers` 에서 관리합니다.

자세한 배포·환경변수 설정은 **[DEPLOY.md](DEPLOY.md)** 를 보세요.

## 데이터 출처와 한계

실서비스는 **전국 17,501곳**(그중 무료 11,737곳)의 실제 스냅샷으로 동작합니다.
`public/data/parkings.full.json` 이 그것이며, 자동 갱신 워크플로우가 월 1회 갱신합니다.

> **인증키가 없는 환경에서는 예시 데이터로 폴백합니다.**
> `public/data/parkings.sample.json` 의 32건은 세 가지 상태와 경계 조건을 만들어 내려고
> **직접 작성한 시연용 데이터**입니다. 요금·운영시간은 실제 값이 아니며,
> 앱은 그 상태에서 목록·상세에 "예시 데이터"라고 명시합니다.
> E2E 테스트도 이 32건으로 고정해 돌립니다(스냅샷은 갱신마다 내용이 바뀌므로).

### 확정된 호출 규격

포털은 데이터셋마다 호출 규격이 다릅니다. 이 데이터셋은 다음과 같습니다.

| 항목 | 값 |
|---|---|
| 엔드포인트 | `api.data.go.kr/openapi/tn_pubr_prkplce_info_api` |
| 페이지 파라미터 | `pageNo` / `numOfRows` (최대 1000) |
| 인증키 | **Encoding 키를 그대로** (URL 인코딩하면 403) |
| JSON 파라미터 | **없음** — 기본이 JSON이며 `dataType` 을 보내면 거부됨 |

`scripts/fetch-parking-data.mjs` 는 이 규격을 하드코딩하지 않고 소수의 요청으로 탐색해
확정합니다. 다른 데이터셋으로 바꿔도 그대로 동작합니다.

- 출처: 공공데이터포털 「[전국주차장정보표준데이터](https://www.data.go.kr/data/15012896/standard.do)」 (250개 기관 제공, 갱신주기 반기)
- 요금·운영시간은 **지자체가 등록한 시점의 값**이며 현장과 다를 수 있습니다.
- 특기사항은 자유 서술이라 모든 표현을 해석하지는 못합니다.
  해석에 추정이 섞인 항목(운영시간 미기재, "야간 무료"처럼 시각이 없는 표현)은
  카드에 **`추정` 뱃지**를 붙여 구분합니다.
- 최종 요금은 현장 안내판을 확인하세요.
