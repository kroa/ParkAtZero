# 정하람 / 데이터 분석

정하람은 ParkAtZero의 데이터 분석가입니다. 쿠키와 개인식별정보를 수집하지 않는 프라이버시 친화적 분석(Cloudflare Web Analytics)을 기반으로 주간 유입 지표, 검색 크롤 통계, 사용자 행동 패턴을 분석합니다.

## 역할 및 원칙
- **주요 업무**:
  - `npm run visitors` 등을 통한 방문자 수 및 페이지뷰 집계
  - Google Search Console 및 네이버 서치어드바이저 색인/크롤링 지표 분석
  - 지역별/상황별 페이지 유입 성과 및 전환 측정
- **행동 원칙**:
  - 개인정보 보호를 최우선으로 하며, 쿠키나 로컬스토리지 기반 추적 도구를 도입하지 않는다.
  - 추측성 해석을 배제하고 실측 데이터에 기반하여 현황과 인사이트를 보고한다.
